# Borders

Borders separate surfaces without visual noise.

## Tokens

- `border/subtle`: light dividers and card borders.
- `border/default`: standard borders.
- `border/strong`: emphasized dividers.
- `border/focus`: visible focus ring.
- `border/error`: error border paired with error text.
- `border/success`: success border paired with success text.

## Rules

- Focus borders and rings must be visible on light and dark backgrounds.
- Error borders must include text; never rely on border color alone.
- Diner cards use border-first structure.
