# Roadmap

Future modules should extend the same token, component, and pattern architecture only after real UI audit.

## Phase 1: Diner Ordering Flow

Status: in progress.

Includes:

- Menu browsing.
- Item detail sheet.
- Cart and checkout.
- Live orders and order status.
- Bill, payment, and split bill.
- Inputs, selection cards, bottom sheets, fixed CTA footer, item card family, status timeline.

## Future Extraction Order

1. Auth forms and onboarding.
2. Dashboard workspace and tables.
3. Billing and payment operations.
4. Analytics charts and filters.
5. Staff/admin workflows.
6. Loyalty and rewards.

## Roadmap Rule

Each future module starts as `not-yet-extracted`. Do not define final typography, density, component, or layout rules until the module is audited and polished from real screens. Cart, checkout, live orders, order status, bill, payment, and split bill remain part of the Phase 1 diner surface.
